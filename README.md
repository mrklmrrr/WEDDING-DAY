## Возможности

- Обложка с кнопкой «Открыть»
- Программа дня, галерея, дресс-код
- Таймер до свадьбы
- Анкета гостя (Formspree) → страница «Спасибо»
- Превью при отправке ссылки в мессенджерах (Open Graph)

## Публикация

```bash
git add .
git commit -m "Полировка: OG, thanks, оптимизация фото"
git push
```

GitHub Pages обновляется из ветки `main` за 1–2 минуты.

В настройках Formspree убедитесь, что домен `mrklmrrr.github.io` разрешён (если включена защита).
